## 重要安全提示

- 温控器上的**火焰图标**仅表示采暖需求，并不证明壁挂炉已经点火。
- SAS2011 接收器的**联网**和**继电器供暖输出**是不同状态。
- **燃气和市电操作必须由具备资质的专业人员完成**；请勿将 220V 接入只允许无源触点的锅炉温控端子，也不要自行短接。
- 原版不同页面有单体型号、温度显示范围等版本差异，本中文版已尽可能显式标记。
