## 安全须知

温控器显示火焰只表示有采暖需求；接收器指示灯响应，也不等于壁挂炉一定点火。要分别验证温控器 → 接收器 → 壁挂炉三段。

**燃气与市电危险**：不要自行拆开壁挂炉、拆接线盒、短接控制端子，不能将 220V 接入仅支持无源触点的室温控制端口。电气接线检测应由合格维修人员执行。
